# ME Soul Card

<Row>
    <ItemImage id="mesoulcard:soul_card" scale="2"></ItemImage>
</Row>

A card upgrade for Applied Energistics 2 that allows you to use the Souls from the network directly in AE2 machines.

No more Soul Surge mess.

## Usage
The upgrade is compatible with ME Interfaces, ME Pattern Providers, Export and Import buses.

Simply insert the Me Soul Card in the upgrade slot of the machine, and it will start using Souls from the ME Network as needed.

## Important Information
Each AE2 machine can tick accelerate up to 6x, just like with Soul Surges.

By default, each block can only be accelerated by 1 AE2 machine at a time when using the upgrade.

This behaviour can be changed in the config file, making it possible to have multiple machines accelerating the same block at the same time.
